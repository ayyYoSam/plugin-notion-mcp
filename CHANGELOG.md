# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - Initial Release

### Added

* One-command installation for the Notion MCP server.
* Automatic client detection for Windows, macOS and Linux.
* Support for Claude Desktop, Cursor, VS Code and Windsurf.
* Secure credential storage using Keytar.
* `plugin doctor` to inspect the local environment.
* `plugin verify` to validate the installation.
* `plugin uninstall` to remove the Notion MCP configuration.
* Automatic configuration backups before changes.
* Cross-platform build pipeline.
* Automated test suite with Vitest.
* TypeScript + ESLint development workflow.
