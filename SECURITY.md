# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅         |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue.

Instead:

* Open a GitHub Security Advisory, or
* Contact the maintainer privately through GitHub.

Please include:

* Plugin MCP version
* Operating system
* Steps to reproduce
* Expected behavior
* Actual behavior

Credential-related issues are treated as high priority.
