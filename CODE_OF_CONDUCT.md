# Contributor Covenant Code of Conduct

## Our Pledge

We are committed to making participation in Plugin MCP welcoming, respectful and harassment-free for everyone.

## Our Standards

Examples of positive behavior include:

* Being respectful and constructive.
* Giving helpful feedback.
* Accepting different viewpoints.
* Focusing on improving the project.

Examples of unacceptable behavior include:

* Harassment or personal attacks.
* Discrimination of any kind.
* Trolling or deliberately disruptive behavior.
* Publishing private information without permission.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

## Scope

This Code of Conduct applies within the project repository, discussions and community spaces.

## Reporting

If you experience or witness unacceptable behavior, please contact the project maintainer through GitHub.
