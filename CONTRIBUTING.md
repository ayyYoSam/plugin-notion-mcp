# Contributing

Thanks for your interest in contributing to Plugin MCP.

## Development setup

Clone the repository and install dependencies.

```bash
git clone https://github.com/ayyYoSam/plugin-notion-mcp.git
cd plugin-notion-mcp
npm install
```

## Build

```bash
npm run build
```

## Run tests

```bash
npm test
```

## Lint

```bash
npm run lint
```

## Pull Requests

Before opening a pull request:

* Keep comments and documentation in English.
* Keep changes focused on a single feature or fix.
* Run `npm run build`, `npm run lint` and `npm test`.
* Add or update tests when behavior changes.

## Coding style

* TypeScript
* ESM modules
* Prefer small, composable functions
* Keep the CLI output clean and consistent
